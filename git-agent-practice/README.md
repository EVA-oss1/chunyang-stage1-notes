# Git + AI Agent 版本管理实践项目
## 项目简介
本项目练习Git代码版本管理，借助VS Code中的Claude（AI Agent）辅助完成Git操作。

## 完成内容
1. 使用Git多次commit提交，生成唯一commit哈希，实现版本快照保存
2. 通过哈希值完成版本回退，找回历史版本
3. 使用Claude辅助：解析git log、编写git命令、排查Git报错
4. 分支操作：创建分支、修改文件、合并分支
